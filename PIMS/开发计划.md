# PIMS 档案管理系统 - 开发计划

## 一、项目概述

### 1.1 项目名称
**PIMS** - Personnel Information Management System（人员信息管理系统）

### 1.2 项目目标
开发一个纯前端的档案管理系统，无需后端服务器支持，支持完整的 CRUD 操作，可直接打开 HTML 文件运行，支持 PWA 离线使用。

### 1.3 技术栈

| 类别 | 技术选型 | 版本 | 说明 |
|------|---------|------|------|
| 构建工具 | Vite | 5.x | 快速构建、原生 ESM |
| 前端框架 | Vue 3 | 3.4+ | Composition API |
| UI 组件库 | Ant Design Vue | 4.x | 企业级组件库 |
| 状态管理 | Pinia | 2.x | Vue 官方状态管理 |
| 路由 | Vue Router | 4.x | 官方路由 |
| Mock | Mock.js | 1.1.0 | 模拟数据生成与拦截 |
| 数据持久化 | LocalStorage | - | 浏览器本地存储 |
| PWA | vite-plugin-pwa | 0.17+ | 离线应用支持 |
| Excel 处理 | xlsx (SheetJS) | 0.18+ | Excel 导入导出 |
| HTTP 请求 | Axios | 1.x | 请求封装 |
| CSS 工具 | TailwindCSS | 3.x | 响应式样式 |
| 语言 | TypeScript | 5.x | 类型安全 |

### 1.4 开发原则

- ✅ **纯前端运行**：无需任何后端服务，双击 HTML 即可运行
- ✅ **数据持久化**：使用 LocalStorage 保存数据，刷新不丢失
- ✅ **响应式设计**：适配 PC、平板、手机多端
- ✅ **亮色主题**：以浅色调为主的 UI 设计
- ✅ **PWA 支持**：可安装到桌面，支持离线使用

### 3.2 核心数据模型

#### 人员档案 (Personnel)

```typescript
interface Personnel {
  id: number
  name: string              // 姓名 *必填
  photo: string             // 人员照片 *必填
  phone: string             // 手机号 *必填
  gender: '男' | '女'       // 性别
  category: string          // 分类
  education: string         // 文化程度
  ethnicity: string         // 民族
  nativePlace: string       // 籍贯
  maritalStatus: string     // 婚姻情况
  idType: string            // 证件类型
  idNumber: string          // 证件号
  birthday: string          // 出生日期
  address: string           // 现居地址
  militaryRank: string      // 军衔
  tags: string[]            // 标签数组
  remark: string            // 备注
  status: 'draft' | 'pending' | 'approved' | 'rejected'  // 状态
  createTime: string
  updateTime: string
}
```

#### 用户 (User)

```typescript
interface User {
  id: number
  username: string          // 用户名
  password: string          // 密码（加密存储）
  name: string              // 姓名
  avatar: string            // 头像
  phone: string             // 手机号
  gender: '男' | '女'
  idNumber: string          // 身份证
  roleId: number            // 角色ID
  tags: string[]            // 标签
  status: 'active' | 'disabled'  // 账号状态
  lastLoginTime: string     // 最近登录时间
  createTime: string
}
```

#### 角色 (Role)

```typescript
interface Role {
  id: number
  name: string              // 角色名称
  permissions: string[]     // 权限代码数组
  createTime: string
}
```

#### 标签 (Tag)

```typescript
interface Tag {
  id: number
  name: string              // 标签名称
  personnelCount: number    // 标签人数
  createTime: string
}
```

## 六、响应式设计规范

### 6.1 断点设计

| 断点 | 尺寸 | 设备 | 布局策略 |
|------|------|------|----------|
| xs | < 576px | 手机竖屏 | 单列布局、侧边栏隐藏 |
| sm | ≥ 576px | 手机横屏 | 单列布局 |
| md | ≥ 768px | 平板竖屏 | 侧边栏折叠 |
| lg | ≥ 992px | 平板横屏 | 正常布局 |
| xl | ≥ 1200px | 桌面 | 完整布局 |
| xxl | ≥ 1600px | 大屏 | 完整布局 |

### 6.2 响应式策略

- **侧边栏**：xl+ 展开，lg 折叠，md- 抽屉模式
- **表格**：xs 使用卡片列表替代，sm+ 使用表格
- **表单**：xs 单列，md+ 双列，lg+ 可三列
- **弹窗**：xs 全屏，sm+ 居中弹窗
