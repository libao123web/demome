# PIMS 打包说明

## 📦 打包版本说明

本项目提供了两种打包版本，适用于不同的使用场景：

### 1️⃣ 静态页面版 (dist-static)

**适用场景**：
- ✅ 需要直接双击打开 HTML 文件运行
- ✅ 无需安装 Web 服务器
- ✅ 本地单机使用
- ✅ U盘/光盘分发
- ✅ 内网环境无服务器部署

**特点**：
- 使用相对路径，所有资源打包成单个 JS 和 CSS 文件
- 可以直接打开 `index.html` 运行
- 不支持刷新（使用 Hash 路由）
- 数据存储在浏览器 LocalStorage
- 文件大小约 2.5MB（已压缩）

**打包命令**：
```bash
npm run build:static
```

**使用方法**：
1. 打包完成后，打开 `dist-static` 目录
2. 双击 `index.html` 文件即可运行
3. 或将整个 `dist-static` 文件夹复制到任意位置使用

**注意事项**：
- ⚠️ 某些浏览器对本地文件有跨域限制，推荐使用 Chrome/Edge
- ⚠️ 首次加载可能需要几秒钟（2.5MB 的 JS 文件）
- ⚠️ 如果页面空白，请检查浏览器控制台是否有错误

---

### 2️⃣ PWA版 (dist-pwa)

**适用场景**：
- ✅ 需要部署到 Web 服务器
- ✅ 需要离线使用功能
- ✅ 需要安装到桌面/手机
- ✅ 需要更好的用户体验
- ✅ 支持自动更新

**特点**：
- 支持离线使用（Service Worker）
- 可安装到桌面/手机主屏幕
- 支持后台自动更新
- 代码分包加载，首屏速度更快
- 更好的缓存策略和性能
- 需要 HTTPS 或 localhost 环境

**打包命令**：
```bash
npm run build:pwa
```

**部署方法**：

#### 方式一：本地预览
```bash
npm run preview:pwa
```
访问 http://localhost:4173

#### 方式二：部署到 Nginx
```nginx
server {
    listen 80;
    server_name pims.example.com;
    root /path/to/dist-pwa;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # PWA manifest 和 Service Worker
    location ~* (manifest\.webmanifest|sw\.js)$ {
        add_header Cache-Control "public, max-age=0, must-revalidate";
    }
}
```

#### 方式三：使用 serve（简单HTTP服务器）
```bash
# 安装 serve
npm install -g serve

# 启动服务
cd dist-pwa
serve -p 8080
```

## 🚀 一键打包两个版本

```bash
npm run build:all
```

打包完成后会生成：
- `dist-static/` - 静态页面版（约2.5MB，单文件）
- `dist-pwa/` - PWA版（约2MB，多文件分包）

## 🎯 推荐使用场景

**选择静态页面版**：
- ✅ 公司内网环境，无服务器
- ✅ 需要分发给多人单机使用
- ✅ U盘/移动存储设备携带
- ✅ 临时应急使用
- ✅ 不想安装服务器环境

**选择PWA版**：
- ✅ 有Web服务器环境
- ✅ 需要团队协作（结合后端）
- ✅ 移动端使用较多
- ✅ 需要最佳用户体验
- ✅ 需要定期更新功能

## 📝 使用注意事项

### 静态页面版常见问题

**Q: 双击 index.html 后页面空白？**
- A1: 使用 Chrome 或 Edge 浏览器打开
- A2: 按 F12 打开开发者工具，查看 Console 面板的错误信息
- A3: 某些浏览器可能阻止本地文件运行脚本，可以用简单的 HTTP 服务器：
  ```bash
  # Python 3
  cd dist-static
  python -m http.server 8000
  
  # Node.js
  npx serve dist-static
  ```

**Q: 首次加载很慢？**
- A: 正常现象，单个 2.5MB 的 JS 文件需要加载时间，后续访问会被浏览器缓存

**Q: 数据会丢失吗？**
- A: 数据存储在浏览器 LocalStorage，除非清除浏览器数据，否则不会丢失

### PWA版常见问题

**Q: 必须使用 HTTPS 吗？**
- A: Service Worker 需要 HTTPS，但 localhost 除外

**Q: 如何安装到桌面？**
- A: 浏览器地址栏会显示"安装"按钮，点击即可

**Q: 如何更新版本？**
- A: 重新打包部署后，PWA 会自动检测并更新
