# PIMS 快速使用指南

## 🎉 打包已完成！

两个版本已成功生成：

### ✅ 静态页面版：`dist-static/`
- 📦 文件大小：2.5MB
- 🚀 使用方法：**双击 `dist-static/index.html` 即可运行**
- 💡 特点：无需服务器，可在任何地方使用
- 📝 详细说明：查看 `dist-static/使用说明.txt`

### ✅ PWA版：`dist-pwa/`
- 📦 文件大小：2.0MB（分包加载）
- 🚀 使用方法：部署到Web服务器或运行 `npm run preview:pwa`
- 💡 特点：支持离线使用、安装到桌面、自动更新
- 📝 详细说明：查看 `打包说明.md`

---

## 📚 快速命令

```bash
# 重新打包静态版
npm run build:static

# 重新打包PWA版  
npm run build:pwa

# 一键打包两个版本
npm run build:all

# 预览静态版
npm run preview:static

# 预览PWA版
npm run preview:pwa

# 开发模式
npm run dev
```
