# 抽屉组件重构说明

## 概述
将项目中所有页面的 Modal 弹窗统一改为 Drawer 抽屉组件，并创建了通用的抽屉组件以避免重复代码。

## 新增组件

### 1. FormDrawer - 表单抽屉组件
**路径**: `src/components/FormDrawer/index.vue`

**功能**: 用于新增、编辑操作的通用表单抽屉

**特性**:
- 响应式宽度：自动适配屏幕大小，至少占 50% 屏幕宽度
- 统一的底部按钮样式（取消 + 确定）
- 支持 loading 状态
- 自定义确认按钮文本

**Props**:
```typescript
interface Props {
  open: boolean        // 是否显示
  title: string       // 标题
  width?: number      // 宽度（默认720）
  loading?: boolean   // 加载状态
  confirmText?: string // 确认按钮文本（默认"确定"）
}
```

**事件**:
- `update:open`: 更新显示状态
- `confirm`: 点击确定按钮
- `cancel`: 点击取消按钮

**使用示例**:
```vue
<FormDrawer
  v-model:open="modalVisible"
  :title="modalTitle"
  :loading="submitLoading"
  @confirm="handleSubmit"
  @cancel="handleCancel"
  :width="700"
>
  <a-form>
    <!-- 表单内容 -->
  </a-form>
</FormDrawer>
```

### 2. DetailDrawer - 详情抽屉组件
**路径**: `src/components/DetailDrawer/index.vue`

**功能**: 用于查看详情的只读抽屉

**特性**:
- 响应式宽度：自动适配屏幕大小，至少占 50% 屏幕宽度
- 只有关闭按钮
- 适合展示详细信息

**Props**:
```typescript
interface Props {
  open: boolean     // 是否显示
  title: string    // 标题
  width?: number   // 宽度（默认700）
}
```

**事件**:
- `update:open`: 更新显示状态

**使用示例**:
```vue
<DetailDrawer
  v-model:open="detailVisible"
  title="人员详情"
  :width="750"
>
  <a-descriptions bordered>
    <!-- 详情内容 -->
  </a-descriptions>
</DetailDrawer>
```

## 优势

### 1. 代码复用
- 不再需要每个页面都编写底部按钮的样式和逻辑
- 统一的宽度计算逻辑
- 统一的 loading 状态处理

### 2. 一致的用户体验
- 所有抽屉都有相同的外观和行为
- 响应式宽度自动适配不同屏幕
- 统一的动画效果

### 3. 易于维护
- 样式调整只需修改组件文件
- 行为变更集中管理
- 新增页面时直接引入组件即可

### 4. 更好的屏幕利用
- 抽屉从侧边滑出，不遮挡主要内容
- 响应式宽度确保在各种屏幕上都有良好显示
- 大屏幕上有更好的空间利用

## 宽度规则

### FormDrawer 宽度计算
```typescript
const computedWidth = computed(() => {
  const screenWidth = window.innerWidth
  const halfScreen = Math.floor(screenWidth * 0.5)
  const minWidth = props.width        // 设定的最小宽度
  const maxWidth = props.width * 2    // 最大宽度为设定值的2倍
  
  // 至少占50%屏幕，但不小于最小值，不大于最大值
  return Math.max(minWidth, Math.min(maxWidth, halfScreen))
})
```

### 各页面推荐宽度
- 简单表单（2-3个字段）：600px
- 中等表单（4-6个字段）：650-700px
- 复杂表单（7+个字段）：750px
- 详情页面：750px

## 迁移指南

如果需要在新页面中使用抽屉组件：

1. **引入组件**
```typescript
import FormDrawer from '@/components/FormDrawer/index.vue'
// 或
import DetailDrawer from '@/components/DetailDrawer/index.vue'
```

2. **替换模板**
```vue
<!-- 旧的 Modal 方式 -->
<a-modal
  v-model:open="modalVisible"
  :title="modalTitle"
  @ok="handleSubmit"
  @cancel="handleCancel"
  :confirmLoading="submitLoading"
>
  <a-form>...</a-form>
</a-modal>

<!-- 新的 FormDrawer 方式 -->
<FormDrawer
  v-model:open="modalVisible"
  :title="modalTitle"
  :loading="submitLoading"
  @confirm="handleSubmit"
  @cancel="handleCancel"
  :width="700"
>
  <a-form>...</a-form>
</FormDrawer>
```

3. **移除不必要的代码**
- 不需要单独处理底部按钮样式
- 不需要手动计算宽度
- 不需要处理遮罩点击逻辑

## 注意事项

1. **保留 Modal 的场景**：
   - 简单的确认对话框（如删除确认）
   - 需要强制用户关注的警告信息
   - 不需要大量表单输入的场景

2. **使用 Drawer 的场景**：
   - 包含多个表单字段的新增/编辑
   - 需要展示详细信息
   - 需要更大空间的操作

3. **响应式考虑**：
   - 抽屉在小屏幕上会自动调整宽度
   - 确保表单在小屏幕上也能正常显示
   - 使用栅格布局适配不同屏幕
